# الاسم والهوية — قرار ما قبل الإطلاق

تم إبقاء `KoraOne Next` كاسم داخلي مؤقت في V0.2 حتى لا يتم تثبيت علامة قد تكون مستخدمة تجاريًا.

## أسماء مقترحة للمرحلة التالية
1. **Vantora11** — حديث، دولي، مناسب لتطبيق نتائج وأخبار.
2. **OrbitXI** — يوحي بعالم كرة القدم والـ11 لاعبًا.
3. **Nuvora Football** — ناعم وقابل لبناء هوية Premium.
4. **Elevenova** — Eleven + Nova؛ مناسب لمنصة “جيل جديد”.
5. **PitchNova** — تقني ورياضي وواضح عالميًا.
6. **Metrika11** — مناسب إذا أردنا إبراز البيانات والإحصائيات.

## التوصية
**OrbitXI** هو الاتجاه الأقوى بصريًا حاليًا، و**Elevenova** هو الأفضل كعلامة استهلاكية سهلة التذكر.

هذه القائمة إبداعية وليست تقرير Clearance قانوني. قبل اختيار الاسم النهائي يجب فحص: النطاق، App Store/Google Play، السوشيال ميديا، وسجلات العلامات التجارية في الأسواق المستهدفة.
