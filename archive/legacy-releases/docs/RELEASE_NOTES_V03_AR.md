# V0.3 — Global Football Platform

هذه نسخة كاملة مبنية فوق V0.2 وليست Patch. أهم الإضافات: Global Search، Player APIs، Transfer Center، Predictions/Leaderboard، Fan Room + moderation، Favorites API، Device Sessions schema، MFA-ready admin fields، صفحات ويب جديدة، Flutter Explore/Transfers/Fan League، وWorkflow مستقل لبناء APK على GitHub بدون Android Studio.

لم يتم تضمين أو نسخ أي محتوى أو شعار أو CSS أو Assets من 365Scores/Kooora/FilGoal/HiHi2. التصميم والشفرة أصلية، والربط مع بيانات المباريات يجب أن يكون عبر مزود مرخص.
