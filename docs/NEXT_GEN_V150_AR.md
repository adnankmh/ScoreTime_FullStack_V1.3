# ScoreTime Global V1.5.0 — Next-Gen Experience

## النقلة النوعية
- واجهة موحدة Premium للويب والموبايل والأجهزة اللوحية.
- Desktop navigation rail + command top bar.
- Hero Command Center بمباراة مميزة وMomentum واحتمالات.
- Match Pulse للمباريات الحية.
- Top News بتصميم تحريري.
- Player Radar وترتيب أداء.
- Tactical Lens: بنية عرض Heatmap/Shot locations.
- Match Momentum visualization.
- Attribute Radar visualization.
- Follow Center + TV Guide + Fan Zone + Transfer Pulse.
- Professional Demo fallback إذا تعذر API.
- نفس Laravel/API/Admin/World Football/Newsroom/Predictions/Social/Transfers/Design Studio السابقة محفوظة.

## ميزات الصناعة المضافة في التجربة
تم تجهيز طبقات UI/architecture لأنماط حديثة شائعة في تطبيقات كرة القدم العالمية مثل xG/shot maps/heatmaps/momentum/player ratings/follow alerts. البيانات الحقيقية لهذه التحليلات تعتمد على مزود بيانات مرخص يدعمها.

## الأمان
- Laravel security headers وCSP/HSTS في الإنتاج.
- Secure token storage في Flutter.
- Admin 2FA/Audit logs كما في الإصدارات السابقة.
- لا توجد مفاتيح API أو .env داخل الحزمة.
