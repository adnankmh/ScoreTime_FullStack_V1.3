# KoraOne — مخطط المنتج

KoraOne منصة كرة قدم مستقلة تجمع بين سرعة النتائج المباشرة وعمق الأخبار والتحليل والإحصائيات، دون نسخ واجهات أو محتوى أو هوية أي منتج قائم.

## الوحدات الأساسية

1. مركز المباريات: أمس/اليوم/غدًا، مباشر، حسب البطولة والدولة والمفضلة.
2. تفاصيل المباراة: timeline، أهداف، VAR، بطاقات، تبديلات، تشكيلات، تقييمات، إحصائيات، H2H، form، جدول البطولة، القنوات الناقلة.
3. البطولات: أخبار، مباريات، ترتيب، هدافون، assists، clean sheets، بطاقات، archive seasons.
4. الفرق: قائمة اللاعبين، المدرب، الملعب، المباريات، الأخبار، الإحصائيات، الانتقالات.
5. اللاعبين: الملف الشخصي، المسيرة، الإحصائيات، الإصابات، العقوبات، التقييمات.
6. الأخبار: عاجل، تحليلات، انتقالات، فيديو، مقابلات، ملفات، tags، topics، related content.
7. المفضلة: فريق/لاعب/بطولة/مباراة، موجز شخصي، تنبيهات دقيقة.
8. الإشعارات: kickoff، lineups، goal، VAR، red card، halftime، fulltime، breaking news.
9. البحث العالمي: فرق، لاعبين، مسابقات، أخبار.
10. لوحة الإدارة: CMS، moderation، live overrides، users، roles، ads، notifications، analytics، audit log.

## وحدات المرحلة الاحترافية

- Match Center لحظي عبر WebSocket/SSE.
- Win probability وxG عند توفرها من مزود مرخص.
- Heat maps / shot maps / average positions.
- محرر أخبار غني + scheduling + SEO + OpenGraph + schema.org.
- PWA للويب، deeplinks للموبايل، universal links.
- نظام اشتراك Premium وإزالة الإعلانات.
- Fantasy / prediction challenges اختيارية.
- Arabic/English أولًا، ثم لغات إضافية.
- Multi-sport-ready domain model مع إطلاق كرة القدم أولًا.

## الملكية الفكرية

لا يتم نسخ HTML/CSS أو الشعار أو الصور أو النصوص أو قاعدة بيانات من Kooora أو 365Scores أو FilGoal أو Hihi2 أو غيرها. تستخدم المراجع فقط لدراسة الأنماط الوظيفية الشائعة. جميع الأصول النهائية يجب أن تكون أصلية أو مرخصة، وبيانات المباريات من مزود API يسمح بإعادة العرض تجاريًا.
