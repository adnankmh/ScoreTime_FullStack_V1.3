# معمارية ScoreTime V1.7.2 للبيانات الحقيقية وحماية الرصيد

## التدفق

```text
مزود مرخص → أوامر Laravel المجدولة → MySQL/Cache → Laravel API → Flutter/Web
```

لا يوجد مفتاح مزود داخل APK أو JavaScript. كل الزيارات العامة تقرأ من ScoreTime فقط.

يمكن تمرير رابط Laravel العام أثناء البناء أو حفظه محلياً من شاشة الإعداد عند أول تشغيل. يقبل التطبيق HTTPS فقط، ويرفض النطاقات الوهمية مثل `example.com` و`.invalid`. تغيير الرابط يحدّث طلبات الشبكة اللاحقة دون وضع مفتاح المزود في التطبيق.

## ميزانية الخطة المجانية

| المسار | السقف اليومي | السلوك |
|---|---:|---|
| جدول اليوم | 1 افتراضياً | طلب واحد عالمي ثم تخزين محلي |
| النتائج الحية | 40 | يعمل فقط داخل نافذة مباراة مخزنة |
| التشكيلات/الإحصاءات/الأحداث | 20 | ثلاث طلبات مجمعة لمباراة أولوية، مع كاش |
| الكتالوج/اللاعبون/الانتقالات/الإصابات | 8 | دوري مميز واحد يتبدل كل يوم |
| احتياطي محمي | 20 | لا يستطيع الجدول الآلي استهلاكه |

يوجد أيضاً حاجز إجمالي ذري يستخدم `Cache::lock`، لذلك لا يمكن لعاملين متزامنين اجتياز الفحص ثم استهلاك الطلب نفسه من الميزانية من دون تسجيله. عند بلوغ أي سقف تتوقف المهمة قبل الشبكة وتبقى بيانات قاعدة البيانات السابقة متاحة.

## الصدق عند فشل المصدر

- `provider/health` و`data-status` يعرضان آخر قياسات مخزنة ولا يتصلان بالمزود.
- Flutter يعيد محاولة طلب GET واحداً عند انقطاع مؤقت أو خطأ 5xx.
- عند الفشل لا تتحول الشاشة إلى نتائج Demo؛ تظهر رسالة واضحة ويمكن السحب للتحديث.
- النسب التحليلية لا تظهر إلا عند توفر ثلاثة لقاءات حديثة على الأقل لكل فريق، وتُوسم كتقدير ScoreTime غير رسمي.
- البث والتشكيلات والتسديدات والزخم تظهر فقط إذا كانت موجودة فعلاً.

## توحيد حالات المباراة

تُحوّل حالات المزود مثل `NS`, `1H`, `HT`, `2H`, `FT`, `PEN`, `PST` إلى حالات داخلية ثابتة:

`scheduled`, `live`, `halftime`, `finished`, `postponed`, `cancelled`, `abandoned`, `suspended`.

القيمة الأصلية تبقى محفوظة في `broadcast_meta.provider_status` لأغراض التدقيق.

## التوسع

لخادم واحد يكفي MySQL وFile Cache. للتوسع إلى عدة خوادم استخدم Redis للكاش والأقفال والـqueues، CDN للصور، read replicas عند الحاجة، ومراقبة للـscheduler وأخطاء المزود. لا يوجد نظام يمكن وصفه بأنه «مستحيل الاختراق»؛ الحزمة تطبق طبقات دفاع عملية ويجب تحديث Laravel/PHP/Flutter والخادم باستمرار.
