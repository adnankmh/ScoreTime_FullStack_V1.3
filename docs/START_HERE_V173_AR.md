# تشغيل ScoreTime V1.7.3 بسهولة

## ما هو «السيرفر»؟

هو مشروع `backend-laravel` الموجود داخل الحزمة. يعمل كطبقة آمنة بين التطبيق ومزود كرة القدم: يحتفظ بالمفتاح، يجلب البيانات وفق حدود الرصيد، يخزنها في MySQL ثم يرسلها إلى Flutter. لا تضع مفتاح API‑Football في شاشة التطبيق.

GitHub Pages يستضيف ملفات Flutter Web الثابتة فقط، ولا يستطيع تشغيل Laravel أو PHP أو MySQL.

## الخيار الأول: معاينة التطبيق فوراً

اضغط **دخول إلى المعاينة**. هذا يفتح الواجهات ببيانات توضيحية معلّمة، ولا يدّعي أنها نتائج حية. يمكنك الانتقال لاحقاً إلى **المزيد → Laravel API** لربط البيانات الحقيقية.

## الخيار الثاني: بيانات حقيقية من الكمبيوتر إلى Android

1. فك الحزمة في مسار بسيط مثل `C:\ScoreTime`.
2. شغّل XAMPP وتأكد أن MySQL يعمل.
3. شغّل `START_SCORETIME_WINDOWS.bat` واترك نافذة Laravel مفتوحة.
4. سيظهر عنوان مثل `http://192.168.1.25:8000/api/v1`.
5. اجعل الهاتف والكمبيوتر على شبكة Wi‑Fi نفسها.
6. اكتب العنوان الظاهر في التطبيق واضغط **اختبار الاتصال وحفظه**.
7. إذا ظهر تنبيه Windows Firewall فاسمح على **Private networks** فقط.

لا تستخدم `127.0.0.1` على الهاتف؛ هذا يعني الهاتف نفسه، وليس الكمبيوتر.

## الخيار الثالث: تشغيل عالمي دائم

انشر مجلد Laravel على استضافة تدعم PHP 8.2+ وMySQL وScheduler، ثم استخدم رابط HTTPS حقيقياً مثل `https://api.your-domain.com/api/v1`. ضع الرابط في متغير GitHub `SCORETIME_API_BASE_URL` ليعمل Web وAPK مباشرة بلا شاشة إعداد.

## بناء APK بلا Android Studio

ارفع الحزمة إلى GitHub ثم شغّل **ScoreTime • Android APK + AAB**. يمكنك ترك عنوان API فارغاً؛ سيبنى APK وتظهر خيارات التشغيل الثلاثة عند أول فتح. اسم Artifact هو `ScoreTime-V1.7.3-Android`.
