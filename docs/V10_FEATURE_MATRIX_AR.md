# ScoreTime V1.0 — Feature Matrix

## Football Core
Live scores, fixtures calendar, competitions, cups, countries, clubs, national teams, players, squads, standings, leaders, lineups, match timeline, cards, substitutions, VAR-ready events, statistics, xG-ready, shot map, momentum, H2H, form, injuries/suspensions, transfers and transfer intelligence.

## Media
Newsroom, breaking news, personalized feed, categories, media library, SEO, sitemap, PWA/offline, dynamic pages and no-code blocks.

## Fans
Favorites, team/match following, notification preferences, predictions, prediction seasons, leaderboards, mini leagues, fan room, friends, challenges, achievements, XP/levels and activity feed.

## Product & Monetization
Premium entitlements, ad slots/campaigns, sponsors, notification campaigns, white-label profiles, A/B experiments, scheduled design publishing.

## Administration
Adnan Control Room, users, audit/security, world data sync, live match operations, content, media, ads, design studio, Experience OS, 2FA and optional admin IP allowlist.

## App/Web Experience
Arabic, English, Turkish, French, Spanish; RTL; remote branding; three theme families; font scaling; remote navigation; dynamic pages; global football directory.
