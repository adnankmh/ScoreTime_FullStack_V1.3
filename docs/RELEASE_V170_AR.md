# ScoreTime V1.7.0 — ملاحظات الإصدار

## ما تم تنفيذه

- الحفاظ على الاسم والشعار وألوان ScoreTime الزرقاء/السماوية/الذهبية.
- واجهة داكنة فاخرة ومتجاوبة للموبايل والتابلت والويب وسطح المكتب.
- روزنامة بالأيام مع مرشح مباشر/قادم/منتهٍ وشعارات حقيقية وتوقيت محلي.
- مركز مباراة يعرض النتيجة والتشكيلات وخريطة التسديدات والزخم والإحصاءات والأحداث والفورمة والتنبيهات عندما تتوفر من المصدر.
- بحث عالمي، أخبار، انتقالات، بطولات، فرق، لاعبون، مفضلة، توقعات، مجتمع ولوحة إدارة/no-code موجودة ضمن البنية السابقة ومحفوظة.
- إرسال لغة المستخدم في `X-Locale` و`Accept-Language`، مع العربية وRTL وخمس لغات إضافية.
- مسارات GitHub Actions محدثة لـFlutter 3.47 وJava 17 وAPK/AAB وWeb وiOS وLaravel.

## إصلاحات جوهرية عن V1.6.1

- منع استهلاك 84 طلباً يومياً قبل دخول أي مستخدم، واستبداله ببوابات زمنية وسقوف مستقلة.
- جعل فحص صحة المزود سلبياً بلا طلب API.
- جعل حجز الرصيد ذرياً ضد تزامن العمال.
- منع محرر التصميم من مسح كاش الرصيد بالكامل.
- توحيد حالات المزود ومنع اختفاء المباريات الحية بسبب `1h/2h/ft`.
- إصلاح قيمة `realtime_state` غير القابلة لـNULL.
- تمرير التعليق الحي الحقيقي إلى مركز المباراة.
- إصلاح مخاطرة `num`/`int` في مؤقت Flutter.
- إزالة fallback الذي كان يعرض Demo عند خطأ الشبكة.
- إزالة نسب 58/24/18 وتقييمات وثقة انتقالات مولدة.
- إيقاف Seeder المباريات والنتائج واللاعبين التجريبي تلقائياً، مع migration ينظف المعرفات القديمة المعروفة.
- إضافة اللغة الألمانية للموقع وتوحيد مفاتيح اللغات الست.
- إزالة كلمة الإدارة الافتراضية وتوليد كلمة قوية مرة واحدة.
- تشفير الجلسات افتراضياً وإضافة رؤوس الأمان إلى API مع الحفاظ على CORS لتطبيق Flutter.
- التحقق من رابط API قبل بناء التطبيق حتى لا ينتج APK غير متصل.

## حدود صريحة

- اكتمال التاريخ والبطولات واللاعبين يعتمد على ترخيص وتغطية مزود البيانات المختار.
- NewsAPI Developer ليس ترخيص نشر تجاري؛ استخدم مصدراً يتيح إعادة النشر أو فريق تحرير أصلي للإنتاج.
- AAB يحتاج مفتاح توقيع خاص بك قبل رفعه إلى متجر Google Play، بينما Workflow ينتج APK اختبار Release قابل للتنزيل.
- الفحص المحلي المرفق يفحص بنية 221 ملف PHP و40 ملف Dart وWorkflows والترجمات. البناء الحقيقي النهائي ينفذ داخل GitHub Actions حيث تتوفر PHP وFlutter.
