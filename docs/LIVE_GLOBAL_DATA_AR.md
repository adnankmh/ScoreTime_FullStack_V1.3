# ScoreTime V1.6 — البيانات العالمية الحقيقية

## المبدأ
ScoreTime لا يعتمد على قوائم ثابتة للاعبين أو نتائج مكتوبة داخل الكود عند تشغيل Live Mode.

### كرة القدم
المزود الأساسي المدعوم:
- API-Football / API-Sports

المزود الثانوي:
- football-data.org

المزامنة تشمل حسب تغطية المزود والخطة:
- الدول
- الدوريات والكؤوس
- المواسم
- الفرق
- اللاعبين
- مباريات اليوم
- النتائج المباشرة
- الدقيقة والحالة
- الأهداف والبطاقات والتبديلات
- التشكيلات
- إحصائيات المباراة
- إحصائيات اللاعبين
- الترتيب
- الهدافين وصناعة الأهداف
- الإصابات
- الانتقالات
- المدربين
- التوقعات
- الكؤوس/الألقاب وسجل الغياب عندما يوفرها المزود

## الأخبار
NewsAPI مدعوم لاكتشاف عناوين الأخبار العالمية.

سياسة ScoreTime:
- نخزن العنوان والوصف المختصر واسم المصدر والرابط والتاريخ.
- لا ننسخ المقال الكامل إلى قاعدة ScoreTime.
- الضغط على الخبر يمكن أن يقود للمصدر الأصلي.
- يمكن تقييد NEWS_ALLOWED_DOMAINS إلى ناشرين لديك حق استخدام محتواهم.

## تشغيل Live Mode على Windows
بعد تشغيل الموقع لأول مرة:
1. شغّل `CONFIGURE_LIVE_DATA_WINDOWS.bat`.
2. أدخل API-Football key.
3. أدخل NewsAPI key.
4. السكربت يقوم بالمزامنة الأولى تلقائياً.

للمزامنة المستمرة:
`php artisan schedule:work`

## الجداول الزمنية
- Live matches: كل دقيقة عندما FOOTBALL_LIVE_SCHEDULER=true.
- مباريات اليوم: كل 10 دقائق عندما FOOTBALL_TODAY_SCHEDULER=true.
- أخبار: كل 15 دقيقة عندما NEWS_SYNC_SCHEDULER=true.
- Catalog: يومياً عند تفعيل FOOTBALL_CATALOG_SCHEDULER.

## أمان المفاتيح

لا تضع مفاتيح API داخل Flutter ولا GitHub Pages.
