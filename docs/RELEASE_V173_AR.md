# ScoreTime V1.7.3 — Easy Connect

- إزالة تجربة الحبس في شاشة Laravel عند غياب رابط API.
- إضافة معاينة فورية اختيارية ومعلّمة بوضوح كبيانات توضيحية.
- دعم ربط Android بخادم Laravel على الكمبيوتر داخل Wi‑Fi نفسه.
- قبول HTTP فقط لعناوين IPv4 الخاصة، مع إبقاء الخوادم العامة على HTTPS.
- جعل مشغّل Windows يستمع على الشبكة الخاصة ويطبع عنوان `/api/v1` الجاهز.
- إضافة إعداد Android اللازم لاتصال LAN مع إبقاء مفتاح المزود داخل Laravel.
- الحفاظ على إصلاح Flutter Web الذاتي وبناء APK/AAB من GitHub Actions دون Android Studio.
