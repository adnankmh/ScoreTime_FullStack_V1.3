# ScoreTime V1.6.1 — الخطة المجانية للبيانات الحقيقية

## API-Football Free
ScoreTime يدعم الخطة المجانية مع حماية للحصة اليومية.

الافتراضي:
- 100 طلب/يوم.
- نحتفظ بـ10 طلبات احتياطية.
- Live global score refresh كل 20 دقيقة = بحد أقصى تقريبي 72 طلب/يوم.
- Calendar اليوم كل ساعتين = 12 طلب/يوم.
- Catalog يومي.
- Lineups / stats / events التفصيلية: عند الطلب + Cache بدل جلبها لكل مباراة تلقائياً.

بهذا لا يحرق التطبيق 100 طلب في أول ساعة.

## التفعيل
بعد تشغيل الموقع:
`SETUP_FREE_API_WINDOWS.bat`

المطلوب منك فقط لصق API Key المجاني مرة واحدة.

المفتاح:
- يبقى في backend-laravel/.env
- لا يدخل Flutter
- لا يدخل APK
- لا يدخل GitHub Pages

## لماذا لا يمكن وضع مفتاح مجاني جاهز داخل الملف؟
كل حساب API-Football يحصل على مفتاح خاص، ووضع مفتاح مشترك داخل مشروع عام سيكشفه ويستهلك الحصة فوراً لجميع المستخدمين.

## football-data.org
مدعوم كمزود ثانوي مجاني. خطته المجانية تغطي عدداً محدوداً من البطولات وبيانات أساسية.

## الأخبار
NewsAPI Developer مجاني للتطوير والاختبار، لكنه ليس بديلاً مجانيًا مناسبًا لإنتاج موقع عام لحظي لأنه يفرض تأخيرًا على المقالات وشروط استخدام مختلفة للإنتاج.
ScoreTime يبقي NewsAPI اختيارياً ولا يضع أي مفتاح في تطبيق العميل.
