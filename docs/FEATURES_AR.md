# ScoreTime V1.7 — نطاق الميزات

## كرة القدم
- مباريات مباشرة وقادمة ومنتهية، Match Center وTimeline.
- التشكيلات التكتيكية، الإحصائيات، H2H، Form، واحتمالات غير رسمية تظهر فقط عند كفاية البيانات.
- بنية Shot Map / xG / Momentum / Heatmap وPlayer Comparison.
- الدول، الدوريات، الكؤوس، المنتخبات، الأندية، اللاعبين، المدربين، المواسم والجداول عبر مزود بيانات مرخص.
- الهدافون، الصناعة، التقييمات، الإصابات والإيقافات والانتقالات بحسب تغطية المزود وترخيصه.
- TV Guide، Calendar، Brackets، Team of the Week، Player Radar وMatch Story.

## الأخبار والمحتوى
- Newsroom ومصادر RSS/API/Partner المسموح بها.
- Attribution + Editorial review + revision history.
- Personalized news/feed وBreaking News.

## المجتمع
- Favorites، Follow Team/Match، Fan Room، Friends، Activity Feed.
- Predictions، Prediction Seasons، Mini Leagues، Challenges، XP، Levels وAchievements.

## الحسابات والأمان
- تسجيل حساب ودخول بالبريد الإلكتروني **أو** Username + Password.
- Sanctum، 2FA للإدارة، Recovery Codes، Audit Logs، Device Sessions، Rate Limiting، IP allowlist اختياري، Security Headers.

## تجربة المستخدم
- English افتراضيًا + العربية + Français + Español + Deutsch + Türkçe.
- RTL للعربية.
- 3 ثيمات + تكبير/تصغير الخط.
- شعار ScoreTime المعتمد + PWA icons + Android launcher assets.

## الإدارة بدون كود
- Experience Design Studio وNo-Code Page Builder.
- ترتيب الصفحة وNavigation وFeature Flags.
- Custom Pages، Design Versions/Rollback، Scheduling، A/B، White Label، Notification Campaigns.
- Media Library، Ads/Sponsors، Newsroom، World Data وOperations.

## صدق البيانات

- لا يعرض Flutter نتائج Demo تلقائياً عند فشل الشبكة.
- التشكيلات والإحصاءات والتسديدات والزخم والبث تظهر فقط عند وجود بيانات فعلية.
- الميزات الموجودة في نموذج البيانات أو لوحة الإدارة ليست وعداً بتغطية مزود الخطة المجانية لكل بطولة أو موسم.
