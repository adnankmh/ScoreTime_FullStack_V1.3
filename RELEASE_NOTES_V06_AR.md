# ScoreTime V0.6 — Visual + Realtime Revolution

V0.6 توسع Match Intelligence إلى Visual Match Data مع Shot Map وMomentum وتشكيلات تكتيكية، Team Hub كامل، Discovery/Trending، Personalized Feed، Fan Levels/XP/Challenges، Premium entitlements، PWA/SEO وControl Center جديد للمدير.

## نقاط الجودة
- فصل visual data عن مزود البيانات.
- APIs جديدة بدون كسر APIs السابقة.
- تشغيل APK عبر GitHub Actions بدون Android Studio.
- PWA مع Service Worker وOffline fallback.
- Sitemap وmetadata أساسية لمحركات البحث.
- حماية صلاحيات المدير و2FA من الإصدارات السابقة محفوظة.
