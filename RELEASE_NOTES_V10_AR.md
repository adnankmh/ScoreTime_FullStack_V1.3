# ScoreTime V1.0

V1.0 هو أول Major Release في المشروع. أهم تغيير هو Global Football Catalog الحقيقي المرتبط بمزود بيانات مرخص: Countries → Competitions/Cups → Seasons/Coverage → Teams/National Teams → Squads/Players → Fixtures/Live Events.

تمت إضافة World Football Directory للموقع والتطبيق، Global Football Data console للمدير، أوامر مزامنة catalog/league/players، Provider IDs وCoverage، Coaches وCompetition Seasons، وإصلاح إعدادات provider لتستخدم متغيرات `.env` بصورة موحدة.

في الأمن تمت إضافة Production Security Headers، optional Admin IP allowlist، إمكانية فرض MFA للإدارة، وتقييد Super Admin افتراضيًا إلى Adnan فقط.

V1.0 يحافظ على كل طبقات V0.1–V0.9: Realtime, Match Intelligence, Visual Match, social/predictions, notifications, premium, media/ads, PWA/SEO, Design Studio وNo-Code Experience OS.
